# ESP32 Python Testing

Python-based integration testing for an ESP32 TCP/JSON API.

## Overview

This repository contains the Python test client and integration tests for an ESP32-based remote control system.

The ESP32 provides a TCP server that receives JSON commands, processes them through a command handler, controls connected hardware, and returns JSON responses.

The purpose of this project is to verify the communication between the Python client and the ESP32 and to systematically test the defined API.

## Project Goals

The main goals of this project are:

- Test the TCP connection between Python and the ESP32.
- Send JSON commands to the ESP32.
- Validate JSON responses.
- Test valid and invalid API requests.
- Test command parameter validation.
- Test events generated by the ESP32.
- Separate the test system from the ESP32 firmware.
- Provide reproducible and maintainable integration tests.

## Architecture

The test environment follows this communication flow:

```text
Python Test Client
        │
        │ TCP / JSON
        ▼
   ESP32 TCP Server
        │
        ▼
   Command Handler
        │
        ├── Display
        ├── RGB LED
        ├── Buzzer
        └── Buttons
```

The Python application acts as an external client.

It does not directly control the ESP32 hardware. Instead, it communicates with the ESP32 through the defined TCP/JSON API.

## Requirements

- Python 3
- ESP32 running the corresponding TCP/JSON server
- ESP32 reachable over the local network
- TCP port `8080`
- Git

## Installation

Clone the repository:

```bash
git clone https://github.com/Dmytro-1506/esp32-python-testing.git
cd esp32-python-testing
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate the virtual environment on Bash:

```bash
source .venv/Scripts/activate
```

Activate the virtual environment on Windows:

```powershell
.venv\Scripts\Activate.ps1
```

Install the project dependencies:

```bash
pip install -r requirements.txt
```

## Configuration

The ESP32 connection requires:

```text
Host: <ESP32 IP address>
Port: 8080
```

An example configuration is provided in:

```text
config/config.example.py
```

The actual local configuration should not contain credentials or other sensitive information.

## Running the Tests

Run the complete test suite:

```bash
python -m unittest discover -v
```

A specific test module can be executed with:

```bash
python -m unittest tests.test_connection -v
```

The tests communicate with a real ESP32.

Therefore, the ESP32 must be:

- powered on
- connected to the network
- running the expected firmware
- reachable from the computer running the tests

## Protocol

The ESP32 API uses JSON messages transmitted over a TCP connection.

A command contains:

- `requestId`
- `type`
- `command`
- `parameters`

Example:

```json
{
  "requestId": "test-ping-001",
  "type": "command",
  "command": "ping"
}
```

The ESP32 returns a response containing the corresponding request ID:

```json
{
  "requestId": "test-ping-001",
  "type": "response",
  "command": "ping",
  "success": true,
  "result": "pong"
}
```

The complete protocol definition is documented in:

```text
docs/protocol.md
```

## Example Test Flow

A typical integration test follows this sequence:

```text
1. Create JSON command
2. Open TCP connection
3. Send command to ESP32
4. Receive response
5. Parse JSON response
6. Validate response
7. Close connection
```

Example:

```text
Python
   │
   │ {"command": "ping"}
   ▼
ESP32
   │
   │ {"success": true, "result": "pong"}
   ▼
Python
   │
   ▼
Assertions
```
